# Getting help

Before opening a new request:

1. Check the [README](README.md) and [latest release notes](https://github.com/Mahdi-mortazavi/purify/releases).
2. Search [existing issues](https://github.com/Mahdi-mortazavi/purify/issues).
3. If the question is about an unsafe behaviour or possible vulnerability, read [`SECURITY.md`](SECURITY.md) first.

For a reproducible bug, open an [issue](https://github.com/Mahdi-mortazavi/purify/issues/new) with your Windows version, Purify version, whether it was elevated, the screen or command involved, and a safe reproduction path. Never include personal paths, private files or drive images.

For ideas and product direction, start a [discussion](https://github.com/Mahdi-mortazavi/purify/discussions) so others can build on it.
